# 学情积分核算自动化

每半月（1-15号）自动从 BI 提取数据并核算学情课包学员的积分发放。

## 快速开始

```powershell
cd C:\Users\fengjianyi\Desktop\方法积分核算\scripts

# 一键运行（本月1-15号）
python run.py --start 2026-05-01 --end 2026-05-15 ^
  --pool-sheet "25-26年5月15号学情课包ID" ^
  --pool-source "上期输出文件.xlsx"
```

## 输出文件

生成的 Excel 包含 5 个 sheet：

1. **汇总** - 每个学生的 LP、小组、总积分、上课时间
2. **获得积分明细** - 学生ID、积分数量、上课日期、课件名称
3. **海外思维学员上课明细** - 完整上课数据 + 3列标注
4. **海外思维续费规划表_学情筛选** - 本期学情课包数据
5. **学情课包ID池** - 累计课包池快照（用于下期）

## 核算规则

- **匹配条件**: `(学生ID, 课时包ID)` 在累计课包池中
- **积分公式**: `(基础课时消耗 + 赠送课时消耗) × 500`
- **发放条件**: 是学情课包 且 积分 > 0
