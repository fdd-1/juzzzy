# 学情积分核算 - 流程文档

## 概述

每半月（1-15号）从 BI 系统提取数据，核算学情课包学员的积分发放明细。

## 数据源

| 报表 | BI名称 | 筛选条件 |
|------|--------|----------|
| 报表1 | 海外思维续费规划表_新版_26年启用 | 当前课包签单年月开始=当月1号, 当前课包签单年月结束=当月15号 |
| 报表2 | 海外思维学员上课明细 | 开始日期=当月1号, 结束日期=当月15号 |

## 处理规则

### 1. 筛选学情课包（报表1）

从续费规划表中筛选 **当前课包名称** 包含"学情"的所有行，提取 `(学员ID, 当前课包ID)` 对。

### 2. 累计课包池

将本期筛选出的学情课包对追加到历史累计池中。池子逐期累加，因为已购买学情课包的学员在课包有效期内都需要发放积分。

### 3. 匹配上课明细（报表2）

对上课明细的每一行，用 `(学生ID, 课时包ID)` 去匹配累计课包池：
- **是否学情课包** = 1（匹配到）或 0（未匹配）

### 4. 计算积分

```
发放积分数量 = (基础课时消耗课时 + 赠送课时消耗课时) × 500
是否符合发放条件 = 1  当且仅当 是否学情课包=1 且 发放积分数量>0
```

### 5. 输出文件

生成 Excel 包含以下 sheet：

| Sheet | 内容 |
|-------|------|
| 汇总 | 每个学生的LP、小组、总积分、上课时间 |
| 获得积分明细 | 学生ID、积分数量、上课日期时间、课件名称 |
| 海外思维学员上课明细 | 完整上课明细 + 3列标注 |
| 海外思维续费规划表_学情筛选 | 本期续费表中学情课包数据 |
| 学情课包ID池 | 累计课包池快照 |

## 使用方法

### 一键运行

```powershell
cd C:\Users\fengjianyi\Desktop\方法积分核算\scripts

# 完整流程（BI取数 + 处理）
python run.py --start 2026-05-01 --end 2026-05-15

# 带历史课包池
python run.py --start 2026-05-01 --end 2026-05-15 --pool "C:\...\历史课包池.xlsx"

# 跳过BI取数（已有下载文件时）
python run.py --start 2026-05-01 --end 2026-05-15 --skip-fetch
```

### 分步执行

```powershell
# 步骤1: 下载报表
python fetch_reports.py --start 2026-05-01 --end 2026-05-15

# 步骤2: 数据处理
python process_xueqing.py ^
  --report1 "..\01_bi_exports\续费规划表.xlsx" ^
  --report2 "..\01_bi_exports\上课明细.xlsx" ^
  --pool "历史课包池.xlsx" ^
  --output "..\03_output\20260501-20260515学情积分发放明细.xlsx"
```

## 课包池管理

- 每期输出的 Excel 中包含"学情课包ID池"sheet，即为当期累计池快照
- 下一期运行时，将上期输出的池作为 `--pool` 参数传入
- 或者使用参考文档中已维护好的池 sheet：`--pool-sheet "25-26年5月15号学情课包ID" --pool-source "参考文档.xlsx"`
