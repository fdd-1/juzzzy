# LP企微朋友圈群发排期与话术生成 Skill

## 功能描述
根据产品内容库和用户画像，为LP（学管）生成差异化的企微朋友圈群发排期和话术建议，支持**港澳台**和**欧美澳**两个地区的定制化内容。

## 触发场景
- 用户说"帮我生成朋友圈排期"
- 用户说"给我写朋友圈文案"
- 用户说"本周/本月朋友圈发什么"
- 用户说"港澳/欧美澳地区朋友圈话术"
- 用户说"针对s3/s5/s9的家长发什么"

## 输入参数
```
region: 港澳台 | 欧美澳          # 必填
stage: s1-s9 | all              # 目标学员阶段，默认all
period: week | month            # 排期周期，默认week
focus: upgrade | retention | renewal | activity  # 营销重点
custom_event: string            # 可选，当前特殊节点（如升阶季、开学季）
```

## 执行步骤

### Step 1: 读取地区画像
读取 `content_library/region_profiles.md`，获取目标地区的：
- 核心诉求和痛点
- 家长决策偏好
- 话术风格偏好

### Step 2: 读取产品卖点
读取 `content_library/product_selling_points.md`，获取：
- 各阶段课程定位
- 核心卖点话术素材
- 升阶/换班政策说明

### Step 3: 生成排期框架
按以下节奏规划一周/一月朋友圈：
- **情感共鸣帖**（1-2条）：贴近家长焦虑/期望，建立信任
- **产品价值帖**（1-2条）：突出课程卖点，对应地区诉求
- **学员成果帖**（1条）：真实案例/学习成果展示
- **互动/福利帖**（1条）：活动预告或学习小tips
- **节点营销帖**（视情况）：升阶季、开学季等特殊节点

### Step 4: 输出话术
每条朋友圈输出：
```
【发送时间】周X XX:XX
【内容类型】情感共鸣/产品价值/学员成果/互动福利
【正文】（150字内，口语化，带1-2个emoji）
【配图建议】
【私聊跟进话术】（可选，针对点赞/评论的家长）
```

## 地区差异化策略

### 港澳台
- **核心诉求**：升学压力、幼小/小初衔接、成绩提升
- **话术风格**：强调学业成果、考试竞争力、名校准备
- **重点阶段**：s1-s3（幼小）、s6-s9（小初衔接）
- **特色活动**：升学季专题、DSE/呈分试备考衔接

### 欧美澳
- **核心诉求**：思维能力培养、国际教育理念、孩子全面发展
- **话术风格**：强调思维训练、探索精神、终身学习
- **重点阶段**：全阶段均衡，s7-s9着重批判性思维
- **特色活动**：数学竞赛备战、思维挑战赛

## 升阶季专项内容
每年统一升阶期间，额外生成：
- 升阶通知朋友圈（官方感强）
- 新阶段课程预热（制造期待）
- 换班/换主讲说明（降低流失）
- LP操作换班换阶的话术指南（私聊用）

## 输出文件
生成结果保存至 `output/` 目录：
- `{region}_{period}_{date}_排期.md`
