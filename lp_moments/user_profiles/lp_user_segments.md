# LP用户分层与画像

## 学员分层维度

### 按阶段分（S1-S9）
- **S1-S3（启蒙期）**：5-8岁，幼小衔接核心人群
- **S4-S6（发展期）**：8-11岁，思维能力快速发展
- **S7-S8（进阶期）**：11-13岁，抽象思维建立
- **S9（衔接期）**：小升初专项，新增阶段课

### 按学习状态分
- **优秀型**：能力强，可考虑上调难度
- **稳定型**：跟随班级节奏，无需特别干预
- **吃力型**：跟不上进度，需考虑下调或加强辅导
- **流失风险型**：出勤率下降、课堂表现差，需重点跟进

### 按家长类型分
- **重视成绩型**（港澳台多）：关注分数、排名、考试
- **重视思维型**（欧美澳多）：关注理解、方法、长期能力
- **观望型**：还在评估课程价值，决策周期长
- **铁粉型**：高满意度，可发展为推荐转介绍

## 不同分层的话术调整

### 对优秀型学员家长
- 朋友圈：分享更高阶的思维内容、竞赛信息
- 私聊：建议尝试上调难度或参加挑战活动

### 对吃力型学员家长
- 朋友圈：发"每个孩子节奏不同"类共情内容
- 私聊：主动关怀，提议换阶或加辅导

### 对流失风险型
- 朋友圈：发学员成长见证类内容唤醒兴趣
- 私聊：主动询问近况，提供解决方案

### 对高意向潜客
- 朋友圈：聚焦产品价值、试听邀请、限时活动
- 私聊：精准推送匹配孩子阶段的课程介绍

## LP工作日历建议

### 日常运营
- **每周3-4条朋友圈**：覆盖不同内容类型
- **每周私聊触达**：重点学员家长（高意向、流失风险）
- **每月活动节点**：至少1次活动或专题内容

### 特殊节点加密
- **升阶季前后2-4周**：加密到每周5-6条
- **大型考试节点**（DSE/会考/小升初）：发相关思维训练内容
- **节假日**：节日祝福+学习小tips
