# 地区用户画像

## 港澳台地区

### 核心特征
- 升学压力极大，名校竞争激烈（香港DSE、澳门考试制度、台湾会考）
- 家长普遍焦虑幼小衔接、小初衔接
- 对学科成绩提升有强烈需求
- 愿意为"有用"的补习投入较高预算
- 决策快，看重口碑和成果案例

### 核心痛点
1. **幼小衔接**：幼儿园升小学竞争激烈，担心孩子输在起跑线
2. **小初衔接**：小学升中学阶段数学难度跳跃大，需要提前准备
3. **成绩追赶**：班级竞争激烈，家长关注孩子排名和成绩
4. **思维跟不上**：应试教育中遇到难题不会举一反三

### 话术偏好
- 强调"提分"、"衔接"、"备考"等关键词
- 用具体成果说话（提升了XX分、通过了XX考试）
- 提及本地考试制度和升学节点
- 口吻可以稍正式，突出专业性

### 营销重点阶段
- **s1-s3**：幼小衔接，数学思维启蒙，赢在小学阶段
- **s6-s9**：小初衔接，提前布局中学数学，s9专攻小升初

### 特色活动建议
- 幼小衔接专题讲座
- 升学季限时优惠
- 本地名校数学题解析
- 模拟考试思维训练营

## 欧美澳地区

### 核心特征
- 教育理念更注重综合素质和思维能力
- 家长希望孩子"真正理解"而非死记硬背
- 对孩子兴趣和自主学习重视度高
- 国际化家庭背景，接受英文/双语教学
- 决策周期较长，注重体验和口碑

### 核心痛点
1. **数学思维弱**：当地课程偏简单，担心孩子数学思维训练不足
2. **华人焦虑**：海外华人家长担心孩子数学比不上国内同龄人
3. **兴趣维持**：孩子对数学不感兴趣，学习主动性弱
4. **思维深度**：能做题但不理解原理，缺乏逻辑推理能力

### 话术偏好
- 强调"思维训练"、"逻辑能力"、"探索精神"
- 聚焦孩子的长期能力发展而非短期成绩
- 用趣味化、探索性的语言
- 结合国际竞赛、STEM等关键词增加认同感

### 营销重点阶段
- **s1-s4**：思维启蒙，让孩子爱上数学
- **s5-s7**：抽象思维进阶，培养真正的数学思维
- **s8-s9**：批判性思维、演绎推理，为未来国际竞赛打基础

### 特色活动建议
- 数学思维公开课（英/中双语）
- AMC/数学竞赛备战营
- 思维挑战月度打卡活动
- "看见孩子进步"成长记录分享
