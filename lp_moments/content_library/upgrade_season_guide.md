# 升阶季专项运营指南

## 升阶季时间节点
每年统一升阶时间通常在：
- **暑假前后**（6-7月）：学年结束，自然升阶节点
- 部分地区可能在寒假后（2月）进行春季升阶

## 升阶季营销节奏

### 升阶前4周：预热铺垫
**目标**：让家长提前了解新阶段价值，降低升阶焦虑

**朋友圈内容方向**：
- 新阶段课程亮点预告
- 上一届升阶学员的成长反馈
- "为什么要升阶"的价值科普

**话术示例（港澳台）**：
```
距离升阶还有一个月，很多家长问我：
"S5升S6，孩子能跟得上吗？"

其实每个阶段的设计都是循序渐进的～
S6会开始接触代数思想和几何推理，
但都是从孩子已有的知识出发，
一步步引导他们建立抽象思维💡

去年升入S6的孩子们，
现在都能独立解决复杂应用题了！
相信你家宝贝也可以～
```

**话术示例（欧美澳）**：
```
Next month, our S5 students will move up to S6! 🎉

S6 is where kids start thinking like real mathematicians—
using algebra, geometry, and logical reasoning to solve problems.

It's not about memorizing formulas,
it's about building a mindset that lasts a lifetime.

Excited to see how they grow! 🌱
```

---

### 升阶前2周：具体说明
**目标**：明确升阶流程，解答家长疑虑

**朋友圈内容方向**：
- 升阶流程说明（换班、换老师）
- 新老师介绍（如有）
- 升阶后的课程安排

**话术示例（港澳台）**：
```
【升阶通知】
本月底，S4班的孩子们将正式升入S5！

升阶后的变化：
✅ 课程难度进阶，开始接触演绎推理
✅ 更换新主讲老师（我会继续跟进大家）
✅ 班级时间可能微调，稍后私聊确认

升阶不是终点，是新的起点～
让我们一起陪孩子迎接新挑战！💪
```

---

### 升阶当周：仪式感营造
**目标**：庆祝成长，增强归属感

**朋友圈内容方向**：
- 升阶祝贺
- 新班级氛围介绍
- 鼓励孩子适应新阶段

**话术示例（港澳台）**：
```
🎊 恭喜我的S3宝贝们顺利升入S4！

看着你们从认识数字到现在能独立解应用题，
真的很为你们骄傲～

S4的数学世界更精彩，
我们一起加油！💪

（配图：孩子们上课的温馨照片）
```

**话术示例（欧美澳）**：
```
Welcome to S4, my little mathematicians! 🎉

You've grown so much—
from counting blocks to solving real-world problems.

This year, we'll explore patterns, logic, and even some algebra!
Can't wait to see what you'll discover. 🚀
```

---

### 升阶后2周：跟进关怀
**目标**：确保学员适应顺利，降低流失

**朋友圈内容方向**：
- 新阶段适应情况反馈
- 学员进步小故事
- 私聊跟进不适应的学员

**话术示例（港澳台）**：
```
升阶两周了，来分享一个小故事～

S6的小宇刚开始觉得几何推理有点难，
但这周他突然跟我说：
"老师，我懂了！原来可以这样想！"

这种"顿悟"的瞬间，
就是数学思维真正建立的时刻💡

每个孩子的节奏不一样，
我们会一直陪着你们～
```

## LP操作换班换阶话术指南

### 场景1：学员觉得太难，想降阶
**私聊话术**：
```
XX妈妈，我注意到孩子最近上课有点吃力，
这其实很正常，升阶初期都有个适应期～

我建议我们先观察两周，
如果还是跟不上，我们可以调整到更合适的班级。

数学学习最重要的是建立信心，
找到适合孩子的节奏才能走得更远💪

您觉得呢？
```

### 场景2：学员觉得太简单，想升阶
**私聊话术**：
```
XX妈妈，我也发现孩子在当前班级表现很好！
确实可以考虑上调难度～

不过我想先确认一下：
孩子是"做得快"还是"真的理解透了"？

如果是后者，我们可以安排试听更高阶的课程，
看看孩子能否适应。

我们的目标是让孩子既有挑战感，又不会压力过大😊
```

### 场景3：升阶后家长担心孩子跟不上
**私聊话术**：
```
XX妈妈，升阶初期有点不适应是正常的～

我会重点关注孩子的课堂表现，
如果真的有困难，我们随时可以调整。

但我建议先给孩子2-3周适应期，
很多孩子一开始觉得难，后来就跟上了💪

我会每周跟您同步孩子的情况，
咱们一起陪孩子度过这个阶段！
```

## 升阶季常见问题FAQ

**Q: 升阶后一定要换老师吗？**
A: 是的，不同阶段由不同主讲负责，但LP（我）会继续跟进您和孩子。

**Q: 孩子能不能不升阶，继续留在原班级？**
A: 原班级会解散，所有学员统一升阶。如果担心难度，我们可以调整到更合适的阶段。

**Q: 升阶后学费会涨吗？**
A: 学费按阶段定价，具体请咨询课程顾问。

**Q: 升阶后时间冲突怎么办？**
A: 我们可以帮您调整到其他时间段的同阶班级。
