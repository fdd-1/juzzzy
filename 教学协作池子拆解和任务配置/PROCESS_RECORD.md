## 一、通用流程框架

### 1.1 流程概览

```
报表导出 → 二次筛选 → 创建标签 → 创建用户群 → 北极星任务 → 标签数据同步
```

### 1.2 技术栈

- **报表导出**：Playwright + SmartBI API
- **数据处理**：pandas（Excel筛选、去重、拆分）
- **标签/用户群**：六一工作台 API（需登录态）
- **北极星任务**：北极星外呼平台 API（需登录态）
- **浏览器自动化**：Playwright（Chromium）

### 1.3 认证要求

1. **六一工作台登录态**：`liuyi_login/auth_state.json`（有效期约7天）
2. **北极星平台登录态**：`polaris_login/auth_state.json`（有效期约7天）
3. **SmartBI凭证**：环境变量 `SMARTBI_USERNAME` / `SMARTBI_PASSWORD`

## 二、P0任务详细流程

### 2.1 任务定义

**任务名称**：P0（学位预警）

**目标人群**：月初剩余总课时1-12的未续费可续学员

**标签命名**：`【海外】26年X月教学协作池-1-12课时低活`

**用户群命名**：同标签名

**北极星任务名**：`【海外】26年X月教学协作池-P0（学位预警）`

### 2.2 执行步骤

#### 步骤1：报表导出（export.py）

**SmartBI筛选参数**：
- 开课M计算时间 = 当月1号（如 2026-06-01）
- 退费结束时间 = 上月最后一天 23:59:59（如 2026-05-31 23:59:59）
- 学管大区 = 海外教学服务部

**输出**：`exports/学位预警_{YYYYMMDD}/海外思维续费规划表_新版_26年启用_{YYYYMMDD}_{HHMMSS}.xlsx`

#### 步骤2：二次筛选（filter.py）

**筛选条件**：
```python
月初剩余总课时 in [1, 2, 3, ..., 12]
是否可续学员 == 1
月初是否续费 == 空（NaN）
```

**输出**：
- `output/dadou_ids_{YYYYMMDD}.xlsx` → 豌豆大账号ID（普通标签用）
- `output/user_ids_{YYYYMMDD}.xlsx` → 学员ID（益智标签用）

#### 步骤3：创建标签（liuyi_tag/create_tag.py）

**标签配置**：
- 普通标签：`【海外】26年X月教学协作池-1-12课时低活` ← dadou_ids
- 益智标签：`【海外】26年X月教学协作池-1-12课时低活（益智）` ← user_ids
- bizCode = WANDOU
- tagType = 531（关键行为）
- dataFrom = 2（USERID）

**输出**：`output/tag_ids_{YYYYMMDD}.json`

#### 步骤4：创建用户群（liuyi_tag/create_group.py）

**用户群配置**：
- 普通用户群 ← 模板16811（豌豆大账号）
- 益智用户群 ← 模板16812（学员ID）

**输出**：`output/group_ids_{YYYYMMDD}.json`

#### 步骤5：克隆北极星任务（polaris_task/update_task.py）

**操作要点**：
- 搜索关键词：`P0（学位预警）`
- 修改字段：任务名称（月份）、用户群（普通群）、教师任务完成时间
- 保持字段：任务类型、启用状态、适用部门、联合收单、跟随转移等

**输出**：`output/polaris_task_{YYYYMMDD}.json`

#### 步骤6：标签数据同步（liuyi_tag/sync_tag_data.py）

**同步配置**：
- 同步用户群：益智群（非普通群）
- 同步业务系统：豌豆数合表
- 同步频率：每天

**输出**：`output/sync_tag_final_{YYYYMMDD}.png`

## 三、P1任务详细流程

### 3.1 任务定义

**任务名称**：P1（服务池协作）

**目标人群**：所有未续费的可续学员（不限课时）

**标签命名**：`【海外】26年X月教学协作池-X月服务池`

**用户群命名**：同标签名

**北极星任务名**：`【海外】26年X月教学协作池-X月服务池`

### 3.2 执行步骤

#### 步骤1：报表导出（同P0）

**SmartBI筛选参数**：与P0完全相同
- 开课M计算时间 = 当月1号
- 退费结束时间 = 上月最后一天 23:59:59
- 学管大区 = 海外教学服务部
- 池子节点3 = 服务月

#### 步骤2：二次筛选

**筛选条件**（与P0不同）：
```python
是否可续学员 == 1
月初是否续费 == 空（NaN）
# 注意：P1 不筛选「月初剩余总课时」
```

**输出**：
- `output/p1_dadou_ids_{YYYYMMDD}.xlsx`
- `output/p1_user_ids_{YYYYMMDD}.xlsx`

#### 步骤3-6：同P0

唯一差异是命名中的「1-12课时低活」改为「X月服务池」

## 五、技术要点

### 5.1 登录态管理

- 六一工作台：有效期约7天，保存在 `liuyi_login/auth_state.json`
- 北极星平台：有效期约7天，保存在 `polaris_login/auth_state.json`
- 过期后重新执行对应的 `login_*.py` 脚本

### 5.2 Playwright自动化

- 使用 `sync_playwright()` 启动浏览器
- 通过 `context.storage_state()` 保存/加载登录态
- 通过 `page.evaluate()` 执行 JS 调用 fetch API

### 5.3 标签上传

- 使用 multipart/form-data 格式
- 在浏览器内通过 JS 构造 File 对象（base64 → Blob → File）
- bizCode=WANDOU, tagType=531, dataFrom=2

### 5.4 用户群创建

- 复制历史模板（16811/16812）
- 修改 `tagsConfig[0].tagIds` 为新标签ID
- 调用 `userGroup/checkData` 预检 + `userGroup/add` 落库

### 5.5 北极星任务克隆

- 搜索历史任务获取完整配置
- 仅修改：任务名称、用户群、教师完成时间
- 其他字段全部保持不变

## 七、常见问题处理

1. **标签创建失败（code=101）**：系统繁忙，稍后重试
2. **用户群创建失败**：检查标签ID是否正确，登录态是否有效
3. **北极星任务搜索失败**：确认搜索关键词能匹配到历史任务
4. **标签数据同步无用户群**：先访问标签页、用户群页刷新缓存
