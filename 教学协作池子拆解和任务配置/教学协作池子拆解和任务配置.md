# 教学协作池子拆解和任务配置

> 创建日期：2026-06-03

## 一、任务分类

教学协作池子拆解分为两大任务：
1. **P0：低课时学员学位预警**
2. **P1：服务池协作**

**任务共同点：**
- 都使用同一张BI报表：`海外思维续费规划表_新版_26年启用`
- 报表筛选的时间参数相同（开课M计算时间、退费结束时间）
- 操作流程相同：下载报表 → 二次筛选 → 创建标签/用户群 → 关联企微 → 北极星任务 → 标签同步

**任务差异点：**
- **二次筛选条件不同**：P0筛选月初剩余总课时1-12，P1筛选月初是否续费=空白
- **标签/用户群命名不同**：P0是"教学协作池-X课时低活"，P1是"教学协作6B-X月服务池"
- **北极星任务名称不同**：P0是"教学协作池-P0（学位预警）"，P1是"教学协作6B-X月服务池"

| 月初是否续费 | 空白 | 仅保留未续费学员 |
| 学员ID | 去重 | 删除重复项 |

**筛选结果输出：**
- 输出文件：`学位预警_筛选结果_<日期>.xlsx`

### 2.3 标签 / 用户群 / 企微标签 / 标签同步

#### 标签命名规则

| 标签类型 | 命名格式 | 上传ID类型 |
| --- | --- | --- |
| 小账号标签（益智） | `【海外】26年X月教学协作池-{课时区间}课时低活（益智）` | 学员ID（2开头） |
| 大账号标签（普通） | `【海外】26年X月教学协作池-{课时区间}课时低活` | 大账号ID |

**说明：**
- `X月` = 当前导出月份
- `{课时区间}` 根据每月筛选总课时数动态确定，常规为 `1-12`
- 例：6月 → `【海外】26年6月教学协作池-1-12课时低活（益智）` / `【海外】26年6月教学协作池-1-12课时低活`

- 用户群名称与标签**同名**（一一对应）
