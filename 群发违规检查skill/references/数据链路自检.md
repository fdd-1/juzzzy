# 数据链路自检

`check.py` 在写出 Excel 之前会打印一段自检表，把 BI 原始行数到最终统计的关键节点全部列出来；任何一步异常都会 `sys.exit(2)`，`run.py` 透传退出码后就不会播报。

## 自检表样例

```
[自检] 数据链路核对
  BI 原始行             12281
  有效违规              12253
  续费场景              11829
  唯一文本              42
  命中报备(剔除)        7124
  未命中                4705
  同LP同文本去重后      109
  最终统计 LP 数        58
  最终违规合计          109
  ✓ 链路一致
```

## 判定规则

| 触发条件 | 处理 | 排查方向 |
|----------|------|----------|
| BI 原始行 / 有效违规 / 续费场景 任一为 0 | `sys.exit(2)` | 报表是否下载成功、列名是否对上、`场景` 列是否还叫「场景」 |
| 续费占比 = 续费场景 / 有效违规 < 5% | `sys.exit(2)` | `场景` 列的取值是否变成了别的字（如「续费续约」「续班」），需要把新词加进 `KEEP_SCENE` 或调成 `contains` 多关键字 |
| 最终违规合计 ≠ 违规明细 sheet 行数 | `sys.exit(2)` | groupby 字段错位，或 `_norm_text` 列没正确生成 |
| 最终违规合计 > 0 但 LP 数 = 0 | `sys.exit(2)` | `小组` / `LP姓名` 列匹配错了 |

## 调试技巧

- 临时跑：`python check.py 海外LP群发违规明细.xlsx --baseline 报备文本.xlsx`，看自检表停在哪一行就知道哪一步出问题。
- 想绕开自检（仅本地排查）：把 `_self_check(...)` 的返回值临时改成 `True`，**禁止把改动提交回主分支**。
- 自检通过但播报数据异常：检查 `_norm_text` 是否过度归一化，把不同模板归到同一字符串。

## 阈值常量

`RENEW_RATIO_WARN = 0.05` 在 `check.py` 顶部，按业务调整。低于这个比例就视为续费场景识别异常。
