# 字段映射

`check.py` 通过 `pick_col()` 模糊匹配实际列名，BI 报表后续改字段只需更新对应列表常量。

## 当前候选

| 标准字段 | 对应常量 | 候选列名 |
|----------|---------|----------|
| 小组 | `GROUP_COL_CANDIDATES` | 小组 / 组别 / 团队 |
| LP姓名 | `LP_COL_CANDIDATES` | LP姓名 / LP / 姓名 / 班主任 |
| 场景 | `SCENE_COL_CANDIDATES` | 场景 / 违规场景 / 群发场景 |
| 违规文本 | `TEXT_COL_CANDIDATES` | 违规文本 / 消息内容 / 群发内容 / 文本 / 内容 |

## 匹配策略

1. 先按候选列表里的优先顺序，找完全相等的列名。
2. 都没命中再走包含匹配（候选词作为子串）。
3. 最终拿到的列名记录在 `check.py` 的输出第 [1] 步打印里，便于核对：

```
✓ 列匹配: 小组=小组, LP=LP姓名, 场景=场景, 文本=违规文本
```

## 表头行不固定

BI 导出的报表 header 可能在 0~3 行（实测下载多在 header=3）。`read_excel_smart()` 会从 header=0 开始尝试，能同时找到 LP 列和文本列就停。

## 改字段时的步骤

1. 先用 `python -c "import pandas as pd; print(pd.read_excel('海外LP群发违规明细.xlsx').columns.tolist())"` 看实际列。
2. 把新字段名加到对应 `*_COL_CANDIDATES` 列表的最前面（保留旧名做向后兼容）。
3. 跑一次 `run.py`，确认 `[1] ✓ 列匹配` 行打印的就是新字段名。
4. 自检表通过 → 提交。
