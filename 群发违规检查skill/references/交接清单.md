# 交接清单

把整个 `群发违规检查skill` 文件夹拷到目标电脑（任意位置、任意用户名）后，按以下顺序检查/配置即可使用，不需要改一行代码。

## 1. 环境

- Python 3.8+（自带 `pathlib`、`difflib`、`re`）
- 依赖：`pip install pandas openpyxl requests`

## 2. 文件

| 文件 | 是否必须 | 来源 |
|------|---------|------|
| `海外LP群发违规明细.xlsx` | 否，`run.py` 会自动下载 | SmartBI「海外后端 / 服务 / 群发 / 海外LP群发违规明细」 |
| `报备文本.xlsx` | **是** | 钉钉文档导出（步骤见下） |
| `海外益智群发日历-LP（主管填写）.xlsx` | 可选，作为 `报备文本.xlsx` 的兜底 | 钉钉文档另一种导出命名 |

## 3. 钉钉报备文档导出

1. 浏览器打开 https://alidocs.dingtalk.com/i/nodes/mExel2BLV542xe22HEGnGE60Wgk9rpMq
2. 右上角「导出」→ Excel
3. 重命名为 `报备文本.xlsx`，放到 skill 根目录
4. 钉钉文档更新时同步替换

> 该文档需要钉钉登录，脚本无法自动抓取，必须手动维护。

## 4. 凭据

钉钉群机器人 webhook 写在 `~/.claude/secrets/intro_monitor.env` 文件里：

```
DINGTALK_WEBHOOK_URL=https://oapi.dingtalk.com/robot/send?access_token=xxx
```

`broadcast.py` 会读这个文件。换电脑/换人时同步把文件 `secrets/intro_monitor.env` 拷过去（注意敏感信息不要提交到代码仓）。

## 5. 依赖外部 skill

- BI 下载脚本：`~/.workbuddy/skills/bi_skill/bi_skill.py`
- 找不到时 `run.py` 会跳过下载、回落到本地 `海外LP群发违规明细.xlsx`。

## 6. 运行

```bash
python <SKILL_DIR>/run.py
```

正常输出末尾会看到：

```
[自检] 数据链路核对
  ...
  ✓ 链路一致
✓ 全部完成
```

任何 `✗ 异常` 行出现都会中止，先读 [数据链路自检.md](数据链路自检.md) 排查。

## 7. 常见交接坑

| 现象 | 原因 | 解决 |
|------|------|------|
| `找不到明细文件` | bi_skill 路径不在 `~/.workbuddy/...` 或没装 | 安装 bi_skill；或手动把明细放进 skill 根目录 |
| `找不到报备文本` | 没导出钉钉文档 | 按上面的步骤导出为 `报备文本.xlsx` |
| `播报：未找到 DINGTALK_WEBHOOK_URL` | `~/.claude/secrets/intro_monitor.env` 缺失 | 拷凭据文件 |
| 自检异常：续费占比 < 5% | BI 改字段，`场景` 列里没有「续费」 | 看 [字段映射.md](字段映射.md) 调 `KEEP_SCENE` 或列候选 |
