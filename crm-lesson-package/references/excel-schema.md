# Excel 配置表约定

本文档约束 Excel 输入格式，便于运营同学按统一口径维护配置表。

## 1. 文件结构

- 单 sheet（默认 `Sheet1`），脚本直接读 `wb.active`。
- 一行 = 一个课时包。
- 一行内是横向 KV：`(label1, value1, label2, value2, ...)`。
- 行首必须是字符串 `课时包名称`（脚本以此识别数据行）。
- 标题行 / 备注行 / 空行随意放，脚本会跳过。

## 2. 必填字段（按顺序）

| 中文 label | 类型 | 示例 | 备注 |
|---|---|---|---|
| 课时包名称 | 文本 | `【VIPTHINK】港澳续费60课时-一续升舱-202606` | 全局唯一 |
| 课包类型 | 文本（叶子） | `中课包` / `年课包` / `季课包` / `两年课包` / `其他类型课包` / `短期包` | 父级默认「常规正课」，特殊情况改 `TYPE_PARENT` |
| 课包分类 | 文本 | `小班直播课` | |
| 有效期 | 整数（月） | `12` | |
| 补课次数 | 整数 | `10` | |
| 普通课时 | 整数 | `60` | |
| 赠送课时 | 整数 | `4` | |
| 原价 | 整数（元） | `7488` | |
| 优惠价 | 整数（元） | `5488` | |
| 试学期 | 整数（天） | `0` | 0 也要写 |
| 打卡次数 | 整数 | `32` | 选完类型后才出现 |
| 停课次数 | 整数 | `1` | 选完类型后才出现 |
| 适用课类 | 文本 | `豌豆思维2024、豌豆明思2024、豌豆明思2025` | 顿号 / 中文逗号 / 英文逗号都能切 |

## 3. 备注行写法

允许在数据行之间放说明，例如：

```
年课包pro请填写成年课包
其他填写为其他类型课包
```

只要这一行第一列不是 `课时包名称`，脚本就跳过。

## 4. 新增列时的两步操作

1. Excel 加新列。
2. `crm_batch_create_lesson_packages.py` 改两处：
   - `HEADER_MAP` 加 `"中文 label": "field_name"`
   - `fill_form` 加 `fill_number(page, "中文 label", data["field_name"])`（按控件类型挑 `fill_text` / `fill_filterable_dropdown` / `fill_multi_select`）
   - 如果该字段是动态出现的（选完某依赖字段才显示），用 `if "field_name" in data:` 守。

## 5. 新增「课包类型叶子」时

改 `TYPE_PARENT`，把新叶子映射到正确的一级父：

```python
TYPE_PARENT = {
    "中课包": "常规正课",
    "年课包": "常规正课",
    "两年课包": "常规正课",
    "新叶子": "常规正课",  # 或别的父
}
```

## 6. 校验示例

跑 `--limit 1` 验证一行能完整过流程，再开全量。第一条成功的判定标准：
- `logs/batch-<ts>.csv` 第一行 `OK`
- CRM 列表搜该名称能搜到
- 弹窗已自动关闭，列表回到默认状态
