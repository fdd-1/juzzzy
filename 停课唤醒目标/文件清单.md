# 文件清单 — 功能与使用频次

每一个会被推到仓库的文件，列清楚 **它做什么**、**多久会跑一次**、**谁会动它**。

> 没列在这里的（`output/`、`*.har`、`*.webm`、`auth_state.json` 等）已被 `.gitignore` 排除 — 那些是开发过程产物或包含真实业务数据，别人复用时应自己跑生成，不需要也不应该看你的实际数据。

## 顶层

| 文件 | 功能 | 使用频次 |
|---|---|---|
| `tingke_wakeup.py` | **主入口**。8 个子命令：`export` / `filter` / `query-dadou-id` / `liuyi-tag` / `liuyi-group` / `wechat-tag` / `polaris-task` / `all` | **每月 1 次**（月初跑 `all --month YYYY-MM`） |
| `SKILL.md` | SKILL 元信息：触发口令、流程图、每个步骤的业务规则 + 接口字段 + 命名约定 | 步骤变更时改 |
| `README.md` | 操作说明：业务背景、命令清单、登录配置、产物结构、故障排查、目录树 | 首次接手项目 / 出问题时查 |
| `.gitignore` | 排除登录态、抓包、录屏、含 PII 的产物 | 不动 |
| `usertag_template-标签模板（豌豆账号）.csv/.xlsx` | 六一工作台「按导入用户id筛选」标签的官方模板（小账号版）。A 列表头「用户id」，从 A2 起填 ID | **几乎不动**（官方模板，复用即可） |
| `usertag_template-标签模板（豌豆大账号）.csv/.xlsx` | 同上，大账号版 | 几乎不动 |

## `liuyi_login/` — 六一统一登录

复用于：步骤 3（平台中心）+ 步骤 4-5（六一工作台标签/用户群）+ 步骤 6（企微）。

| 文件 | 功能 | 使用频次 |
|---|---|---|
| `login_liuyi.py` | 扫码登录 `https://login.61info.cn/`，前后截图验证，落 `auth_state.json` | **JWT 过期时跑**（约 7~30 天 1 次） |
| `enter_liuyi.py` | 复用登录态进六一工作台首页，截图验证 | 调试用，正式流程不需要 |

## `pingtai_query/` — 步骤 3：平台中心批量用户查询

把学员 ID 转换成豌豆大账号 ID（六一/北极星侧识别的是豌豆大账号 ID）。

| 文件 | 功能 | 使用频次 |
|---|---|---|
| `prepare_template.py` | 从 `output/filtered_*.xlsx` 提学员 ID，写到「导入用户id」格式的 xlsx | 每月 1 次（被 `query-dadou-id` 自动调） |
| `query_dadou.py` | Playwright 进平台中心 → 新建批量用户查询 → 上传 ID → 选「豌豆大账号」→ 提交 → 轮询处理结果 → 下载 OSS 导出文件 | 每月 1 次 |
| `record_demo.py` | 录屏 + HAR 抓包（开发期用，对照 UI 提取接口契约） | 接口变更时跑，正常运营不动 |
| `inspect_har.py` | 解析 HAR 列出所有 API（开发用） | 接口变更时跑 |

## `liuyi_tag/` — 步骤 4-6：六一工作台标签 / 用户群 / 企微标签

| 文件 | 功能 | 使用频次 |

| `inspect_har.py` / `dump_key_apis.py` / `dump_addwithfile.py` / `dump_wechat_apis.py` | HAR 分析工具（开发用） | 接口变更时跑 |

## 首次接手怎么用

```bash
# 1. 装依赖
pip install playwright pandas openpyxl
playwright install chromium

# 2. 配 BI（参考 ~/.workbuddy/skills/bi_skill/ 自身说明）

# 3. 扫码登录两个平台
python liuyi_login/login_liuyi.py
python polaris_login/login_polaris.py

# 4. 一键跑当月
python tingke_wakeup.py all

# 或指定月份
python tingke_wakeup.py all --month 2026-06
```

每月只需要重复第 4 步；登录态过期了重新跑第 3 步。
