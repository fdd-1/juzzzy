**服务指标统计表**（海外思维学管服务指标统计表）：

**关键点**：

- 服务指标：使用月初到周末（5.01-5.25），LP 做工时间同样从月初开始，确保 48h/72h 及时跟进率统计窗口正确

### 2. 数据整合脚本

创建 `export_4_1_html_v2.py`，核心功能：

**数据加载**：
- `load_first_call()`：读取首通监控，提取团队级（LP=总计）和个人级数据
- `load_service()`：读取服务指标统计表，提取首课/首专字段
- `build_merged()`：合并两份数据，统一团队名，按层级和团队排序

**字段映射**：
```python
首通监控 → 首通_新生数, 首通_勿扰人数, 首通_一家多娃数, 
          首通_跟进率, 首通_及时跟进率, 首通_企微绑定率, 首通_秒挂占比

服务指标 → 首课_新生数, 首课_勿扰人数, 首课_跟进率, 首课_及时跟进率
          首专_新生数, 首专_勿扰人数, 首专_跟进率, 首专_及时跟进率
```

**结论生成**（`generate_conclusions()`）：
- 读取整体值，判断是否达标（首通 95%、首课 85%、首专 85%）
- 找出低于目标的小组，按值从低到高排序
- 对每个未达标小组，追踪到个人，列出前 5 名最低的 LP
- 企微绑定率：找出低于整体值的小组

### 3. HTML 渲染

**表格结构**：
- 分组标题行（第 1 行）：基础（灰底黑字）、首通/首课/首专（蓝底白字）
- 列名行（第 2 行）：每列底色对应所属分组色
- 数据行：汇总行黄底加粗，个人行白底

**冻结实现**（CSS）：

## 关键技术点

### 1. BI 导出日期规则

**自然周定义**：周一到周日（ISO 8601）

五月 2026 自然周划分：
- 第一周：5.05-5.11
- 第二周：5.12-5.18
- **第三周：5.19-5.25** ← 本次数据范围

**日期参数设置**：
- 首通监控：周范围（5.19-5.25），因为是周度快照
- 服务指标：月初到周末（5.01-5.25），因为包含累计指标（如首课/首专学员数）
- LP 做工时间：从月初开始（5.01-5.25），确保及时跟进率的 48h/72h 窗口计算正确

### 2. 表格冻结的层级管理

**z-index 分层**：
- 普通单元格：无 z-index（默认 0）
- 冻结列：`z-index: 5`
- 冻结表头：`z-index: 10`
- 冻结表头 + 冻结列交叉：`z-index: 15`

**sticky 定位**：
- 表头：`top: 0` 和 `top: 29px`（第二行相对第一行偏移）
- 左侧列：`left: 0`, `left: 50px`, `left: 140px`（累计宽度）

### 3. 结论生成逻辑

**目标值**：
```python
TARGETS = {
    "首通_及时跟进率": 0.95,  # 95%
    "首课_及时跟进率": 0.85,  # 85%
    "首专_及时跟进率": 0.85,  # 85%
}
```

**追踪规则**：
1. 读取海外团队（合）整体值
2. 判断是否达标，输出整体结论
3. 遍历各小组（排除台湾组），找出低于目标的
4. 对每个未达标小组，从个人级数据中筛选该组成员
5. 找出低于目标的个人，按值从低到高排序，取前 5 名
6. 输出格式：`小组名 及时跟进率 XX%，未达目标` + `└ 需关注：LP1(XX%) / LP2(XX%)`
