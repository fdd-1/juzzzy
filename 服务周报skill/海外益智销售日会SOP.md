## 2. 总体执行顺序

1. 如用户要求新建当天日会，先从模板复制文档并改当天日期；如用户给定现有文档，则直接更新。
2. 用飞书 CLI `sheets +info` 读取 spreadsheet 信息，确认 sheet id 是否与本文一致。
3. 按模块顺序跑 Smartbi，导出 Excel。
4. 用 `openpyxl` 解析 Excel，按模块规则生成写入矩阵。
5. 用飞书 CLI 写入指定数据区。
6. 写入后读回关键区域，检查表头、数字格式、百分比、合并单元格、色阶和底部备注。
7. 基于已写入数据，自动生成各团队核心问题，并写入团队下方高亮色块。

## 15. 格式与校验规则

- 不贴 Smartbi 底部 `口径说明`。
- 不把 Smartbi 筛选条件行写入飞书数据表。
- 不覆盖用户已经做好且不需要更新的表头、合并单元格和自动公式。
- 百分比列写底层数值，例如 `0.0573`，通过飞书格式显示为 `5.73%`。
- 金额、人数、课量默认使用数字格式，必要时保留整数。
- 宽表分块写入，避免命令长度限制。
- 写入后必须读回：
  - 首行表头
  - 核心汇总行
  - 中间关键团队行
  - 尾部最后 3-5 行
- 如果新增行，必须修复边框、居中、数字/百分比格式。
- 如果模板要求合并单元格，先补齐值，再按连续相同值合并。
