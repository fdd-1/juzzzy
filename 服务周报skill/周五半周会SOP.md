# 周五半周会 SOP

本文档用于后续自动更新「周五半周会」飞书文档中的转介绍与销售侧内容。后续用户只提供新的飞书文档链接，默认按本文档执行，不依赖模板里是否保留文字说明。

## 1. 执行原则

- 只操作当前周五半周会文档，不复用历史文档 sheet id 作为写入目标；历史 token/sheet id 仅作定位参考。
- 每次先用飞书 CLI/API 读取当前文档 blocks 与嵌入表格信息，按模块标题和表头重新识别目标 sheet。
- SmartBI 数据必须来自 Excel 导出或 SmartBI CLI 结果，不使用截图或页面肉眼结果替代。
- 优先使用 SmartBI CLI / Chrome Browser Use 后端导出，避免 Codex 内置浏览器下载受限。
- 优先使用飞书 CLI/API 写入嵌入表格；只有 API 无法稳定定位正文表格时，才使用浏览器定位加剪贴板粘贴兜底。
- 只写数据区，保留模板表头、颜色、边框、合并单元格和公式。
- 百分比写真实数值，让飞书按百分比格式显示；不要把数字写成文本，避免绿色小角标。
- 数量、人数、课量、分发数、拨打次数写整数；通时、GMV、ASP 等小数按模块要求保留 2 位以内。
- 空白尾行、重复表头、底部口径说明、无效空列必须清理。
- 每个模块写入后立即读回关键区域，校验表头、首行、尾行、公式区、颜色和行数。

## 3. 日期口径

- 执行日：用户发起更新要求当天。
- 执行日前一天：多数月度/转介绍模块的结束日期。
- 当月口径：当月 1 日到执行日前一天。
- 本周二到周五资源周期：执行日所在周的周二到执行日。
- 通时通次本周期：执行日前两天所在周三 00:00 到周四 23:59 或用户指定当前时点。
- 整体课量老人课量：执行日当天 00:00 到执行日后天 23:59，取应到课数。
- 人均课量应到课：执行日当天 00:00 到执行日所在周周日 23:59。
- 若模板标题包含旧日期，写入数据时同步改成当前日期口径。

- 分欧美澳、港澳两块写。
- 重点看最新批次的约课率。

- 不套旧文案，必须基于当次写入数据生成。

### 6.5 分组与计算

小组：

- `CC01组`
- `CC11组`
- `CC16组`
- `英语CC组`
- `港澳CC02组`
- `港澳CC03组`
- `台湾CC02组`

汇总：

- 大海外 = `CC01组 + CC11组 + CC16组 + 英语CC组`
- 港澳 = `港澳CC02组 + 港澳CC03组`
- 台湾 = `台湾CC02组`
- 总计（含台湾）= 全部小组
- 总计（不含台湾）= 剔除台湾CC02组

公式：

- 约课比 = `(老人课量 + 老人分发数) / 周一到四的课量`
- 老人人均 = `老人课量 / 老人人数`
- 环比上周 = `老人人均 / 上周同期 - 1`

写入：

- 保留模板表格样式。
- 不留多余空白单元格。
- 不出现绿色小角标。
- 上周约课比、上周同期按模板/历史当前值复制，不随意清空。

## 7. 课量对于 GMV 预测

报表：

```text
分析报表\海外直播业务线\海外前端\益智_海外前端\业绩达成\益智海外团队渠道业绩达成
```

筛选：

- 开始时间：默认。
- 结束时间：默认。
- 分发类型：`TMK定向分发例子`、`TMK约课分发例子`、`辅投CC约课例子`。

字段与公式：

- 老人课量 = 上一张「整体课量」表的老人课量。
- 预估到课 = 老人课量 × `约课到课率目标`。
- 预估到课转化 = 预估到课 × `到课转化率目标`。
- 预估 GMV = 预估到课转化 × `1.1` × `滚动ASP`。
- GMV 目标 = 目标表 `思维销售目标` sheet 中小组目标的 GMV 目标；找不到先留空。
- 本周进度预估 = 预估 GMV / GMV 目标。

注意：

- 必须包含 `英语CC组`。
- 写入后抽查预估 GMV 公式是否正确。

## 13. 交付前检查清单

每次完成后必须检查：

- 当前文档链接与用户提供链接一致。
- 目标模块 sheet id 由当前文档重新识别，不误写历史表。
- 每个 SmartBI 导出文件存在，筛选条件符合 SOP。
- 表头没有丢失或错位。
- 百分比列显示为百分比，数量列不是百分比。
- 没有绿色小角标。
- 没有多余空白尾行/尾列。
- 公式区未被覆盖，环比/达成率可正常计算。
- 总结框已基于本次真实数据更新。
- 最终回复用户时简要说明已更新模块、关键校验结果和残留风险。

## 14. 后续自动执行触发

当用户后续发送新的周五半周会飞书链接，并说更新半周会、转介绍、销售侧、业务-销售侧或类似要求时：

1. 解析飞书文档，定位转介绍和销售侧模块。
2. 重新识别所有嵌入表格 token/sheet id。
3. 按本文档模块顺序导出 SmartBI Excel。
4. 生成写入矩阵，只写当前模块数据区。
5. 写入后读回校验。
6. 更新总结框。
7. 向用户简要汇报完成情况。
