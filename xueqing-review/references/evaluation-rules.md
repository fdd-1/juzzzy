# 学情总结评估规则

本文件是 `xueqing-review` skill 评估逻辑的**唯一权威来源**。`xueqing_review.py` 在抽查时按此规则判定，输出 Excel 的「评估规则」sheet 也仅给概要并指回此文件，避免代码与规则两边维护不同步。

## 模板匹配标准

学情总结需包含以下结构才视为「符合模板」：

| 阶段 | 主题 | 必含关键词 |
|------|------|-----------|
| s1-3 | 学员兴趣 | 专注力、记忆犹新、学习兴趣 / 课堂活跃度 |
| s4-6 | 学员习惯 | 学习习惯、记忆犹新、笔记草稿 |
| s7-9 | 学员成绩 | 校内成绩、记忆犹新 |

**通用关键词（所有阶段都需包含至少 3 个）：** 记忆犹新、较好知识点、需要提升知识点、家长痛点、未续费顾虑点

**格式要求：** 需包含编号条目（如 `1.xxx 2.xxx`），至少 5 个。

## 详尽描述关键词（优秀的额外门槛）

「优秀」要求 1-3 点描述详尽，反馈学员具体情况。代码用 `DETAIL_KEYWORDS` 常量识别这些维度：

- 课堂参与度 / 参与度
- 兴趣度 / 学习兴趣
- 进步点 / 进步
- 专注度 / 专注力

匹配模板的条目必须**全部**至少命中 1 个上述关键词，才能拿优秀。否则降为合格①。

## 特殊情况（合格②路径）

以下开头视为特殊情况，**不要求按模板反馈**，但仍计入老师的总条目数：

- 停课、退费、请假、不续费、已流失、已转走、已续费、转介绍

特殊情况由代码 `SPECIAL_CASE_PATTERNS` 维护。新增类型时同步两边。

## 反模式黑名单（命中即判不符合模板）

抽查脚本会逐条比对以下反模式，命中任一项就标注为「不符合模板」并附上原因：

| 反模式 | 触发条件 | 原因 |
|--------|---------|------|
| **课后反馈模板** | 出现「今日课堂 / 课堂表现 / 课堂笔记 / 课堂作业 / 今天上课 / 本节课 / 本堂课表现」等关键词 | **不要用课后反馈模板替代学情总结模板**：课后反馈聚焦单节课的课堂行为/作业完成，学情总结要按阶段输出『记忆犹新 / 较好知识点 / 提升知识点 / 家长痛点 / 未续费顾虑点』等结构化结论 |
| **续费销售话术** | 出现「续费优惠 / 限时活动 / 本周下单 / 名额有限 / 早鸟价 / 赠送课时」等 | 销售话术不属于学情评估维度 |
| **日报流水账** | 以「早上 / 中午 / 下午 / 晚上 / 今天 + 上课 / 做题 / 讲了 / 学了」开头 | 学情总结需要按阶段维度结构化输出，而不是按时间叙述 |
| **无评估的知识点复述** | 仅以「讲解了 / 复习了 / 学习了 / 完成了 …」开头且无评估结论 | 必须给出『较好 / 需提升 / 家长痛点』等评估结论，不能只罗列教学内容 |
| **万能套话** | 以「此学员 / 该学员 / 这个孩子 / 这位学员 + 表现良好 / 需要努力 / 继续加油 / 很棒」结尾 | 必须落到具体知识点和家长沟通点，不能用通用话术收尾 |

> 维护方式：发现新反模式时，把 `(正则, 名称, 解释)` 三元组追加到 `xueqing_review.py` 的 `ANTI_PATTERNS` 常量，**同时**更新本表格。两边必须同步。

## 不符合模板的其他情况

- 太短的文本（15 字以内）
- 状态杂项（已加微、待跟进、待沟通、未接、已满）
- 无编号结构的自由文本
- 命中反模式黑名单

## 评级标准（3 级）

> 用户口径：
> - 优秀：学情总结按模板反馈，1-3 点描述详尽，反馈学员的具体情况（如：课堂参与度、兴趣度、进步点、专注度），并完成个性化反馈
> - 合格：① 学情总结按模板反馈，完成个性化反馈；② 停课退费等特殊情况
> - 不合格：① 学情总结未按模板反馈；② 学情总结存在同质化问题（与历史学情总结高度相似、不同学员学情总结高度相似）；③ 未完成个性化反馈

代码实现（按从严到宽顺序判定）：

| 评级 | 判定条件 |
|------|---------|
| **不合格①** | 存在未按模板反馈的条目（且不是特殊情况） |
| **不合格②/③** | 匹配条目 ≥ 2 且平均相似度 ≥ 55%（同质化高 / 个性化未完成） |
| **合格②** | 全部条目均为停课退费等特殊情况 |
| **优秀** | 全部按模板反馈 + 全部匹配条目都命中 ≥ 1 个详尽描述关键词 + 个性化达标（≤ 1 条匹配，或 ≥ 2 条匹配且平均相似度 < 55%） |
| **合格①** | 全部按模板反馈 + 个性化达标，但缺少详尽描述关键词 |

> 「优秀」相比 v2.1 的差异：以前要求平均相似度 < 35%，现在改为「< 55% 即可，但必须命中详尽描述关键词」，与用户最新口径对齐。

## 同质化计算

使用 `SequenceMatcher` 算法计算同一老师**匹配模板**的多条学情总结两两之间的文本相似度，取平均值。
- 相似度区间：[0, 1]，越接近 1 表示同质化越严重
- **个性化判定阈值：** 平均相似度 < 0.55 视为完成个性化反馈
- 特殊情况条目不参与同质化计算

## 抽样覆盖率自检

抽查脚本在抽样后会自动执行覆盖率自检：

- **指标：** `抽样老师数 / 全部有学情总结的老师数`
- **默认阈值：** 80%（通过 `--min-coverage` 调整，例如 `--min-coverage 0.6`）
- **未通过时：** 终端会打 `⚠ 未通过` 并建议把 `--sample` 调高到达标值；输出 Excel 的「评估规则」sheet 顶部也会标红记录本次自检结果。
- **使用建议：** 不通过时优先提升 `--sample`；只有在确认是抽查目的就是小样本（如临时复核个别老师）时才调低 `--min-coverage`。

## 颜色标注（输出 Excel）

- 绿色 = 优秀 / 模板匹配
- 黄色 = 合格 / 特殊情况
- 红色 = 不合格 / 不匹配
