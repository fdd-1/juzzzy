# 学情总结抽查自动化

从 SmartBI 导出「教学&学管协作跟进明细」报表，按老师维度抽样评估学情总结是否符合模板、同质化程度，输出格式化的 Excel 抽查结果并可一键播报到钉钉群。

## 触发方式

用户说以下类似内容时触发：
- "抽查学情总结"
- "学情总结质量检查"
- "检查老师学情反馈"
- "学情抽查"
- "按当月维度做学情抽查"

## 路径与跨机器使用

脚本不再绑定特定用户名/桌面路径。`WORKDIR`（输入和输出 Excel 所在目录）按以下优先级解析：

1. CLI 参数 `--workdir`
2. 环境变量 `XUEQING_WORKDIR`
3. `~/Desktop/学情抽查/`（如果存在）
4. 当前命令的工作目录

调用脚本时使用相对路径或 skill 名称，**不要硬编码 `~/.workbuddy/...` 或 `Desktop/...`**。

## 使用方式

### 端到端（推荐）

下载最新数据 + 按当月过滤 + 抽查 + 钉钉播报：

```bash
python3 xueqing_review.py \
  --workdir "$XUEQING_WORKDIR" \
  --download --monthly --broadcast --sample 5
```

### 仅基于现有 Excel 抽查

```bash
python3 xueqing_review.py \
  --input "<导出的Excel路径>" \
  --output "<输出路径>" \
  --sample 20
```

### 参数说明

| 参数 | 必填 | 默认 | 说明 |
|------|------|------|------|
| `--workdir` | 否 | 见上文路径解析 | 工作目录（输入/输出文件根目录） |
| `--input` | 否 | `<workdir>/教学&学管协作跟进明细.xlsx` | 已导出的明细 Excel 路径 |
| `--output` | 否 | 按日期生成 | 输出 Excel 路径 |
| `--sample` | 否 | 20 | 抽样老师数量 |
| `--min-coverage` | 否 | 0.8 | 抽样覆盖率自检阈值（抽样老师 / 全部老师 ≥ 此比例才通过） |
| `--seed` | 否 | 42 | 随机种子（确保可复现） |
| `--end-date` | 否 | 今天 | 过滤截止日期 YYYY-MM-DD |
| `--pool` | 否 | （益智）海外学管2026年5月协作池-豌豆-6月服务池 | 当月协作池标签（BI筛选） |
| `--download` | 否 | False | 调用 `export_report.py` 重新从 BI 下载 |
| `--monthly` | 否 | False | 按当月维度过滤（学情总结创建时间 ∈ 当月1号~end_date） |
| `--broadcast` | 否 | False | 抽查完成后将结果摘要播报到钉钉群 |

### 钉钉播报配置

播报使用钉钉自定义机器人 webhook，URL 从 `~/.claude/secrets/intro_monitor.env` 的 `DINGTALK_WEBHOOK_URL` 读取。该文件未配置时会跳过播报并打印提示。

## 评估规则

完整评估规则（模板匹配标准、各阶段关键词、**反模式黑名单**、**特殊情况识别**、**详尽描述关键词**、评级标准、同质化计算、**抽样覆盖率自检**）维护在 [references/evaluation-rules.md](references/evaluation-rules.md)，是规则的唯一权威来源。代码侧 `ANTI_PATTERNS` / `SPECIAL_CASE_PATTERNS` / `DETAIL_KEYWORDS` 三个常量与规则文档一一对应，新增项需同步两边。

### 评级口径（v2.3）

- **优秀**：学情总结按模板反馈，1-3 点描述详尽，反馈学员的具体情况（命中『课堂参与度 / 兴趣度 / 进步点 / 专注度』等关键词），并完成个性化反馈（平均相似度 < 55%）
- **合格 ①**：学情总结按模板反馈，完成个性化反馈，但描述维度不够详尽
- **合格 ②**：全部为停课 / 退费等特殊情况，不要求按模板
- **不合格 ①**：存在未按模板反馈的条目（且非特殊情况）
- **不合格 ②/③**：同质化高（与历史 / 其他学员相似度 ≥ 55%）= 未完成个性化反馈

### 判定流程

1. 命中反模式黑名单 → 直接判不符合模板
2. 命中特殊情况关键词 → 走合格 ② 路径，不参与模板判定与同质化计算
3. 否则按阶段（s1-3 / s4-6 / s7-9）匹配主题与必含关键词
4. 检查通用关键词命中数与编号条目数
5. 用 SequenceMatcher 在匹配模板的条目间计算平均相似度
6. 综合输出 优秀 / 合格 / 不合格 三档评级（详见 references/evaluation-rules.md）

## 输出格式

Excel 包含 3 个 Sheet：

1. **抽查总览**：老师姓名、艺名、学情总数、符合模板数、不符合数、特殊情况数、阶段、同质化评估、综合评级
2. **详细条目**：每条学情总结的具体内容、是否匹配（特殊情况标黄）、详尽描述命中、特殊情况标签、评估说明
3. **评估规则**：本次抽样覆盖率自检结果 + 规则概要 + 指向 references/evaluation-rules.md

颜色标注：绿色 = 优秀 / 模板匹配、黄色 = 合格 / 特殊情况、红色 = 不合格 / 不匹配。

钉钉播报内容（仅结果，不发送 Excel）：
- 抽样老师数量
- 优秀 / 合格 / 不合格 计数
- 每位老师的 评级 + 评估说明（markdown 表格）

## 抽查后验证步骤

抽查脚本运行完成后，执行以下检查确认结果可信，再决定是否播报或汇报给上级：

1. **抽样覆盖率自检**：终端输出 `[3.5] 抽样覆盖率自检` 须为 `✅ 通过`。未通过时按提示提高 `--sample` 重跑，或在确认是小样本场景时显式降低 `--min-coverage`。
2. **输出文件存在性**：确认目标 Excel 已生成，路径与 `--output` 一致，文件大小 > 0。
3. **三个 Sheet 完整**：打开输出 Excel，确认 `抽查总览`、`详细条目`、`评估规则` 三个 Sheet 均存在且非空。
4. **抽样数量校验**：`抽查总览` 中老师行数应等于 `--sample` 设定值（若可用样本不足会更少，需在终端日志中能看到提示）。
5. **评级分布抽看**：随机抽 1 位「优秀」和 1 位「不合格」老师，对照 `详细条目` 中该老师的学情总结原文，验证评级与文本表现一致。
6. **关键词命中复核**：在 `详细条目` 中检查匹配度列，确认评分与 [references/evaluation-rules.md](references/evaluation-rules.md) 的关键词规则一致，无明显误判。
7. **反模式标注复核**：抽 1-2 条命中反模式的记录，对照 references 中的反模式黑名单确认未误判（避免把合格学情误打成「课后反馈模板」等）。
8. **同质化合理性**：对「不合格」或「优秀」老师，肉眼比对其多条学情总结，确认相似度评估方向正确。
9. **钉钉播报核对**（仅 `--broadcast` 时）：在群里查看播报消息，确认计数与 `抽查总览` 一致，markdown 表格无格式错乱。
10. **异常日志排查**：终端输出中若出现 `WARNING` / `ERROR` / 跳过提示，需先定位原因再交付结果。

任一项不通过：先修正数据或参数，重新跑一次，不要直接交付/播报。

## 依赖

- Python 3.10+
- pandas
- openpyxl
- playwright（仅 `--download` 时需要）

## 注意事项

- 数据表头在第 10 行（`HEADER_ROW=9`），学情总结列名为「学情总结」
- 抽样优先选择有 ≥ 2 条学情总结的老师（评估更准确）
- 默认随机种子 42，确保每次抽样结果可复现
- 如需更换协作池，通过 `--pool` 传入新标签
- 钉钉机器人 webhook 配置在 `~/.claude/secrets/intro_monitor.env`
