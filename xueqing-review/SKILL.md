# 学情总结抽查自动化

从 SmartBI 导出「教学&学管协作跟进明细」报表，按老师维度抽样评估学情总结是否符合模板、同质化程度，输出格式化的 Excel 抽查结果并可一键播报到钉钉群。

## 触发方式

用户说以下类似内容时触发：
- "抽查学情总结"
- "学情总结质量检查"
- "检查老师学情反馈"
- "学情抽查"
- "按当月维度做学情抽查"

## 使用方式

### 端到端（推荐）

下载最新数据 + 按当月过滤 + 抽查 + 钉钉播报：

```bash
python3 ~/.workbuddy/skills/xueqing-review/xueqing_review.py \
  --download --monthly --broadcast --sample 5
```

### 仅基于现有 Excel 抽查

```bash
python3 ~/.workbuddy/skills/xueqing-review/xueqing_review.py \
  --input "<导出的Excel路径>" \
  --output "<输出路径>" \
  --sample 20
```

### 参数说明

| 参数 | 必填 | 默认 | 说明 |
|------|------|------|------|
| `--input` | 否 | `Desktop/教学协作/学情抽查/教学&学管协作跟进明细.xlsx` | 已导出的明细 Excel 路径 |
| `--output` | 否 | 按日期生成 | 输出 Excel 路径 |
| `--sample` | 否 | 20 | 抽样老师数量 |
| `--seed` | 否 | 42 | 随机种子（确保可复现） |
| `--end-date` | 否 | 今天 | 过滤截止日期 YYYY-MM-DD |
| `--pool` | 否 | （益智）海外学管2026年5月协作池-豌豆-6月服务池 | 当月协作池标签（BI筛选） |
| `--download` | 否 | False | 调用 `export_report.py` 重新从 BI 下载 |
| `--monthly` | 否 | False | 按当月维度过滤（学情总结创建时间 ∈ 当月1号~end_date） |
| `--broadcast` | 否 | False | 抽查完成后将结果摘要播报到钉钉群 |

### 钉钉播报配置

播报使用钉钉自定义机器人 webhook，URL 从 `~/.claude/secrets/intro_monitor.env` 的 `DINGTALK_WEBHOOK_URL` 读取。该文件未配置时会跳过播报并打印提示。

## 评估规则

### 模板匹配标准

学情总结需包含以下结构才视为「符合模板」：

| 阶段 | 主题 | 必含关键词 |
|------|------|-----------|
| s1-3 | 学员兴趣 | 专注力、记忆犹新、学习兴趣/课堂活跃度 |
| s4-6 | 学员习惯 | 学习习惯、记忆犹新、笔记草稿 |
| s7-9 | 学员成绩 | 校内成绩、记忆犹新 |

**通用关键词（所有阶段都需包含至少3个）：** 记忆犹新、较好知识点、需要提升知识点、家长痛点、未续费顾虑点

**格式要求：** 需包含编号条目（如 1.xxx 2.xxx），至少 5 个。

### 不符合模板的情况

- 太短的文本（15字以内）
- 状态备注（已转走、已续费、停课等）
- 无编号结构的自由文本
- 使用课后反馈模板而非学情反馈模板

### 评级标准（3 级）

| 评级 | 条件 |
|------|------|
| **优秀** | 同一老师所有学情总结都符合模板（结构和内容都匹配），且每个学生收到的内容都做到差异化（平均相似度 < 35%，至少 2 条） |
| **合格** | 结构和内容与模板一致即为合格：包括「全部符合模板」（无论差异化高低）和「部分符合模板」两种情况 |
| **不合格** | 所有学情总结的结构和内容都不符合模板（如短文本、无编号结构、缺少关键词、课后反馈备注等） |

### 同质化计算

使用 SequenceMatcher 算法计算同一老师多条学情总结两两之间的文本相似度，取平均值。

## 输出格式

Excel 包含 3 个 Sheet：

1. **抽查总览**：老师姓名、艺名、学情总数、符合模板数、阶段、同质化评估、综合评级
2. **详细条目**：每条学情总结的具体内容、是否匹配、匹配度、评估说明
3. **评估规则**：本次评估的规则说明

颜色标注：绿色 = 优秀、黄色 = 合格、红色 = 不合格。

钉钉播报内容（仅结果，不发送 Excel）：
- 抽样老师数量
- 优秀 / 合格 / 不合格 计数
- 每位老师的 评级 + 评估说明（markdown 表格）

## 依赖

- Python 3.10+
- pandas
- openpyxl
- playwright（仅 `--download` 时需要）

## 注意事项

- 数据表头在第 10 行（`HEADER_ROW=9`），学情总结列名为「学情总结」
- 抽样优先选择有 ≥ 2 条学情总结的老师（评估更准确）
- 默认随机种子 42，确保每次抽样结果可复现
- 如需更换协作池，通过 `--pool` 传入新标签
- 钉钉机器人 webhook 配置在 `~/.claude/secrets/intro_monitor.env`
