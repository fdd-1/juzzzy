# Excel 配置表约定

本文档约束 Excel 输入格式，便于运营同学按统一口径维护配置表。一份 Excel 同时驱动课时包和套餐的创建。

## 1. 文件结构

- 单 sheet（默认 `Sheet1` 或自定义名），脚本读 `wb.active`
- 一行 = 一个 SKU（课时包 + 同名套餐）
- 一行内是横向 KV：`(label1, value1, label2, value2, ...)`
- 行首必须是字符串 `课时包名称`
- 标题行 / 备注行 / 空行随意放，脚本会跳过

## 2. 必填字段（13 个，按列出现顺序无要求）

| 中文 label | 类型 | 示例 | 备注 |
|---|---|---|---|
| 课时包名称 | 文本 | `【VIPTHINK】欧美澳续费38课时-总监特批-202606` | 全局唯一；套餐名与课时包名相同 |
| 课包类型 | 文本（叶子）| `中课包` / `年课包` / `年课包pro` / `季课包` / `两年课包` / `两年包` / `其他类型课包` / `其他` / `短期包` | 父级默认「常规正课」；自动映射规则见下 |
| 课包分类 | 文本 | `小班直播课` | |
| 有效期 | 整数（月）| `9` | |
| 补课次数 | 整数 | `6` | |
| 普通课时 | 整数 | `38` | |
| 赠送课时 | 整数 | `2` | |
| 原价 | 整数（元）| `5088` | |
| 优惠价 | 整数（元）| `3788` | |
| 试学期 | 整数（天）| `0` | 0 也要写 |
| 打卡次数 | 整数 | `20` | 选完课包类型后才出现的字段 |
| 停课次数 | 整数 | `1` | 选完课包类型后才出现的字段 |
| 适用课类 | 文本 | `豌豆思维2024、豌豆明思2024、豌豆明思2025、豌豆明思2026` | 顿号 / 中文逗号 / 英文逗号都能切 |

## 3. 可选字段

| 中文 label | 类型 | 示例 | 备注 |
|---|---|---|---|
| 赠送礼品 | 文本 | `海外特批16000豌豆币` | 用于套餐创建。礼品名必须在 CRM 中已存在；空或不填 = 套餐不绑礼品 |

## 4. 课包类型自动映射

Excel 名称与 CRM 实际选项不一致时，脚本会自动映射：

| Excel 名称 | CRM 实际选项 |
|---|---|
| `年课包pro` | `年课包` |
| `两年包` | `两年课包` |
| `其他` | `其他类型课包` |

如需新增映射，修改 `crm_batch_create_lesson_packages.py` 中 `parse_excel` 函数内的 `mapping` 字典。

## 5. 备注行写法

允许在数据行之间放说明，例如：

```
标黄的列请不要动
年课包pro请填写成年课包
其他填写为其他类型课包
两年包请填写成两年课包
```

只要这一行第一列不是 `课时包名称`，脚本就跳过。

## 6. 新增列的两步操作

1. Excel 加新列（如「视频课节数」）
2. `crm_batch_create_lesson_packages.py` 改两处：
   - `HEADER_MAP` 加 `"中文 label": "field_name"`
   - `fill_form` 加对应控件填充（按控件类型挑 `fill_text` / `fill_number` / `fill_filterable_dropdown` / `fill_multi_select`）
   - 如果该字段是依赖出现的（选完某依赖字段才显示），用 `if "field_name" in data:` 守

## 8. 校验流程

跑 `--limit 1` 验证一行能完整过整套流程：

1. 课时包创建：`logs/batch-<ts>.csv` 第一行 `OK`
2. CRM「课时包管理」搜该名称能搜到
3. 套餐创建：`logs/package-batch-<ts>.csv` 第一行 `OK`
4. CRM「套餐管理」搜该名称能搜到
5. 弹窗已自动关闭，列表回到默认状态

通过后再开全量 + `--skip-existing`。
