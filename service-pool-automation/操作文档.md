# 海外益智服务池学员自动化处理 - 操作文档

## 📋 概述

本工具实现了海外益智服务池学员名单的自动化处理流程，包括：
- BI 报表下载和筛选
- 学员流转数据匹配
- 六一工作台标签创建
- 数仓同步

**执行时间**：约 3-5 分钟/次  
**执行频率**：每月一次  
**难度等级**：⭐（简单）

## 📊 输出文件说明

### 主输出文件

**路径**：`data/processed/服务池学员_YYYYMM.xlsx`

**Sheet1**：完整数据（所有学员信息）
- 包含 BI 报表的所有原始列（89列）
- 最右侧新增 2 列：
  - `最终归属LP`：根据学员流转匹配后的 LP
  - `最终归属小组`：根据学员流转匹配后的小组

**Sheet2**：六一标签数据（仅大账号ID）
- 仅包含 `大账号ID` 一列
- 用于上传到六一工作台创建标签

### 日志文件

**路径**：`logs/service_pool_YYYYMMDD_HHMMSS.log`

包含详细执行日志，用于排查问题。

## ⚠️ 常见问题和解决方法

### ❌ 问题1：BI 报表下载失败

**错误信息**：`BI 报表下载失败: xxx`

**可能原因**：
- BI 系统登录超时
- 网络问题
- bi_skill.py 路径不正确

**解决方法**：
1. 检查 `config.json` 中的 `bi_skill_path` 是否正确
2. 手动测试 bi_skill.py 是否可用
3. 查看日志文件获取详细错误

### ❌ 问题2：学员流转文件找不到

**错误信息**：`学员流转文件不存在: xxx`

**解决方法**：
1. 确认文件路径是否正确（注意反斜杠需要双写 `\\`）
2. 使用绝对路径，不要使用相对路径
3. 或者使用命令行参数手动指定：
   ```bash
   python service_pool_automation.py --liuzhuang-file "正确的路径.xlsx"
   ```

### ❌ 问题3：六一工作台操作失败

**错误信息**：`六一标签创建失败: xxx` 或 `数仓同步失败: xxx`

**可能原因**：
- 登录态过期
- 网络问题
- 脚本路径不正确

**解决方法**：
1. 重新登录六一工作台：
   ```bash
   python C:\Users\fengjianyi\Desktop\六一标签\login.py
   ```
2. 检查 `config.json` 中的 `liuyi_create_path` 和 `liuyi_sync_path`
3. 或者使用 `--skip-liuyi` 先生成数据，再手动操作

### ❌ 问题4：数据匹配不符合预期

**症状**：所有学员的「最终归属LP」都等于「LP姓名」，没有匹配到学员流转

**可能原因**：
- 学员流转文件列名不正确
- 数据类型不匹配（学员ID 格式问题）

**解决方法**：
1. 打开学员流转文件，确认包含以下列名（完全一致）：
   - `学员id`
   - `新班主任姓名`
   - `新班主任组别`
2. 查看日志文件中的匹配统计：
   ```
   匹配到学员流转: X 条
   未匹配（使用原LP）: Y 条
   ```

### ❌ 问题5：中文乱码

**症状**：帮助信息或日志中的中文显示为乱码

**解决方法**：
这不影响脚本执行，仅影响显示。如需解决，可以：
1. 使用 UTF-8 编码的终端（如 Windows Terminal）
2. 或者忽略显示问题，直接查看日志文件（日志文件中文正常）
