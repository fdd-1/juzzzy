# BI 报表必备字段

报表名：**海外益智主订单宽表**（`profile_name`）。

## 必备字段

| 字段 | 用途 | 缺失影响 |
|---|---|---|
| 用户ID | 与正式池 join | 无法做人群匹配，整个流程跑不下去 |
| 套餐名称 | 套餐分类 | `PACKAGE_CATEGORIES` 失效，全部归"其余" |
| 用户实际支付金额 | 计算 ASP / 单课时价 | 无法算金额类指标 |
| 课时数（含积分） | 含积分单课时价 | 该列缺失 |
| 课时数（不含积分） | 不含积分单课时价 | 该列缺失 |
| 订单支付时业绩归属人五级部门 | 区域筛选 | 串区 |
| 区域等级 | 区域筛选 | 串区 |
| 支付时间 | 期间筛选 | 月份对不上 |

## 表头检测

`extract_data.py` 以 **"用户ID"** 为锚点定位表头行。锚点找不到时**直接报错**"BI报表表头结构变更"，不要 fallback 到列号硬编码——硬编码会在下次列顺序变化时静默错位。

## 字段名变更应对

BI 改字段名是常事。改名后：

1. 先抽 1 行报表看字段全称（注意"五级部门"全称是 "**订单支付时业绩归属人五级部门**"）
2. 改 `extract_data.py` 中的字段引用 + `config.py` 中 `REGION_FILTERS` 的 key
3. 更新本文档对照表
4. 跑一次完整流程，看校验恒等式是否成立

## 期间约定

复盘默认跑**上一个完整月**。月中跑当月会因订单未结金额偏低，ASP 失真。如必须跑当月，在报告里**明确标注"截止日期"**，并提示读者结果未完结。
