# 套餐分类规则

权威配置在 `config.py` 的 `PACKAGE_CATEGORIES`。**列表顺序即匹配优先级**，命中即停。

## 当前优先级（从上到下）

```python
PACKAGE_CATEGORIES = [
    ("升舱",     "升舱"),
    ("早鸟",     "早鸟"),
    ("全量限定", "全量限定"),
    ("学情限定", "学情限定"),
    ("SVIP",     "SVIP"),
    ("全量",     "全量"),
    ("其余",     "其余"),
]
```

每个 tuple：`(套餐名匹配关键字, 输出分类标签)`。匹配方式是 `if keyword in 套餐名`。

## 关键约束

- **"全量限定" 必须排在 "全量" 前**。"全量限定"包名里也含"全量"，顺序反了会被错分。
- **"学情限定" 同理**。
- "其余" 兜底——如果"其余"占比 > 5%，说明有新套餐没覆盖，要在 SVIP 之后、"全量"之前增加新规则，而不是任由其落入"其余"。

## 加新套餐的步骤

1. 抽样查 BI 中近一个月的套餐名 distinct 列表
2. 决定新套餐属于哪一类（升舱/早鸟/限定/SVIP/全量/其余）
3. 在 `PACKAGE_CATEGORIES` 对应位置插入新关键字。位置很重要——更具体的关键字必须在更宽泛的关键字之前
4. 跑一次复盘，确认"其余"占比降下来
