# 对标阈值

权威配置在 `config.py` 的 `DEVIATION_THRESHOLDS`。

## 公式

```
偏差 = (实际值 - 预算值) / 预算值
```

## 阈值

| 偏差绝对值 | 颜色 | 处理 |
|---|---|---|
| ≤ 5% | 绿 / 无标记 | 正常 |
| 5% – 15% | 🟡 黄 | 报告"关注项"段，附数据来源 |
| > 15% | 🔴 红 | 报告"异常项"段，**必须人工复核**才能交付 |
| 预算缺失 | ⚪ 灰 | 标"无预算"，不参与偏差统计 |

## 预算缺失 vs 解析失败

两者**视觉上都是灰**，但含义不同——必须区分：

- **预算缺失**：SKU 测算文档里这一类本来就没有预算（如新套餐尚未列入测算）。报告里标"无预算"是对的。
- **解析失败**：SKU 测算文档存在该类预算，但 `extract_budget_from_sku` 异常没读到。当前代码会 `try/except` 打 `⚠`，但偏差对标会变成"无预算"——结论失真。

排查解析失败：
1. 看运行日志的 `⚠` 警告
2. 在报告顶部明确"本期未对标"
3. 修复 `analyze.py` 的 `extract_budget_from_sku`，重新跑

## 调阈值

如果业务侧觉得 5% / 15% 不合适，改 `DEVIATION_THRESHOLDS` 后**记得同步本文档**，并在月度复盘里说明阈值变更，否则偏差结论无法跨月对齐。
