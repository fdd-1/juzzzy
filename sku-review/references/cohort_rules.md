# 人群分类规则

权威配置在 `config.py` 的 `COHORT_RULES`。

## 规则

```python
COHORT_RULES = {
    1:     "一续",
    "gt1": "多续",   # 当前课包顺序 > 1
    0:     None,     # 池外，必须排除
}
```

字段来源：正式池文件中 **"当前课包顺序"** 列。

## 易错点

- ❌ 顺序 = 0 当多续 —— 0 是"池外"，必须排除而非归入多续
- ❌ 把"一续 + 多续"当成"全部订单" —— 还有一类是"池外（顺序=0）"被排除掉
- ✅ 校验恒等式：**一续订单数 + 多续订单数 + 排除订单数 = 筛选后订单总数**

## 正式池其他必备字段

- `用户ID`：与 BI 报表 join key
- `当前课包顺序`：上面的核心字段
- `池子节点2`：用于映射 SKU 节点（升舱/早鸟池），见 `POOL_NODE2_TO_SKU`

## 文件命名约定

- 文件名包含"正式池"，如 `4月正式池-04.01-v1.xlsx`
- sheet 名固定为 `池内（剔已续不可续）`（见 `POOL_SHEET_NAME`）
- 4月复盘必须用 4月正式池，不能延用 3月——人群边界对不上
